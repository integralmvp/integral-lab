# CUBE 운영 LAB — 시연 가이드

> ⚠ **화면의 모든 단가는 시연용 임시값입니다.** 실제 거래 단가·거래처·품목이 아니며,
> 거래처명(가상상사A…)·품목명(품목A…)도 가상 값입니다. 화면 상단 "시연용 예시 단가" 배지가 상시 표시됩니다.

## 1. 실행

```bash
npm install
npm run dev
```

| 주소 | 화면 |
|---|---|
| `http://localhost:5173/?mode=admin` | 운영 화면 (접수 / 배차·운송 / 정산·기록 / 메시지, 실무자·대표 토글) |
| `http://localhost:5173/?mode=field` | 현장 모바일 화면 (휴대폰 또는 좁은 창) |
| `http://localhost:5173/?mode=quote` | 기존 관리자 견적 화면 (단일 화물 견적 시뮬레이터) |
| `http://localhost:5173/` | 기존 화주 화면 (변경 없음) |

**시연 직전 반드시** 운영 화면 우측 상단 **"데모 초기화"**를 한 번 누른다.
(이전 브라우저 데이터가 남아 있으면 새 시드 시나리오가 보이지 않는다.)
관리자 창과 현장 창은 같은 브라우저의 두 탭(또는 두 창)으로 띄운다 — 탭 간 실시간 동기화.

## 3. 권장 시연 순서

1. **접수 창** — 대시보드(총 접수 / 화주앱 유입 / 오프라인 / 상태별)를 보여주고, ORD-001 행을 눌러
   구간별 견적 근거(적용 단가행·역할·실단가·수량·청구큐브 2,500·5t)를 펼친다. ORD-003의 "단가 미등록" 배지를 짚는다.
2. **수기 등록** — 미리 채워진 값 그대로 "접수 등록" → 즉시 3구간 분해 + 견적 합계 표시.
3. **메시지 패널(우측)** — R2 단가 미등록, R1 미견적, R3 배차 대기 지연, R5 정산 대기를 보여준다.
   "대표" 토글로 일일 요약(R6)을 보여준다.
4. **배차·운송 창** — ORD-001 내륙 구간 "배차". 선사·도내 구간은 버튼이 비활성이고
   "이전 구간(내륙) 완료 후 배차 가능" 사유가 표시됨을 보여준다(구간 순서 가드).
5. **현장 창(`?mode=field`)** — 방금 배차된 구간이 크게 뜬다. "상차 완료 → 출발 → 하차 완료"를 누르면
   관리자 칸반이 실시간으로 이동한다. 완료 후 메시지에 R4 "다음 구간 배차 필요"가 뜬다.
6. **정산·기록 창** — ORD-008 "정산 확정" → 매출/매입/마진 합계 갱신, 하단 이벤트 기록에서
   모든 변경이 이벤트로 쌓였음을 보여준다.
7. (선택) **`?mode=quote`** — 단일 화물 큐브 좌표·차종 탈락 사유(선초과) 시뮬레이터.

## 4. 알려진 한계 (정책상 이번 범위 밖)

- R7(마진 임계) 메시지 없음 — 매입은 `매출 × 0.82` 시연 상수.
- 화주앱 Deal → Order 실제 연동 없음 — "화주앱 유입"은 시드 3건.
- 경로 사전은 축약판 (키워드 → 권역, 선사명 → 출발항).
- 이벤트 타임라인 필터·차트, 금액 마스킹(DEMO_MASK) 토글 UI 없음.
- 배차 후 실제 차량이 매칭 차종과 달라도 재견적하지 않음.
- 백엔드 없음: 데이터는 브라우저 localStorage(`lab:` 키)에만 저장 — 같은 브라우저 안에서만 동기화.

## 5. 문제 시 복귀 절차

이 보강판은 `lab-r2` 브랜치다. 화면이 깨지거나 이상하면 안정판 `lab`으로 돌아간다.

```bash
git checkout lab
```

```bash
npm run dev
```

그 다음 운영 화면에서 **"데모 초기화"**를 누른다. (localStorage 데이터가 꼬였을 때도 초기화로 복구된다.
초기화 버튼이 안 보이면 브라우저 개발자도구에서 `lab:`로 시작하는 localStorage 키를 삭제 후 새로고침.)
